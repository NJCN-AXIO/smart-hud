# 68 v1.0.61：关闭超速提醒；写控制器路径封死

## 背景

- 用户拍板：超速提醒关闭；满电续航 estRange 每箱实际里程自动改写的行为保留。
- 写控制器路径已在 `analysis/67` 评估封死：不向任何特征写值，只读红线维持。

## 改动

| 位置 | 改动 |
|---|---|
| `Prefs.speedLimit()` | 默认值 30 → 0（关闭） |
| `Prefs.migrateSpeedOff()` | 一次性迁移：仍是旧默认 30 的设备置 0；用户自己改过的值不动；flag `mig_speed_off` 落盘 |
| `HudState.speedLimitKmh` | 默认 30 → 0 |
| `HudScreen.speedColor` | `lim <= 0` 时不再退回 25 黄 / 35 红，时速一律主题色，不做超速变色 |
| `MainActivity` 设置行 | 说明文案改为“超过语音报一次并变红；0 = 关闭” |
| `BleService` 语音提醒 | 原有 `lim > 0` 闸门不变，阈值 0 时天然不触发 |

## 未改动

- estRange 自动改写（`BleService` 底部按本箱实际里程回写）保留。
- 语音总开关、里程/电量/GPS 逻辑全部不动。
- 红线：仍无任何 `writeCharacteristic`，唯一写仍是 CCCD `01 00`。
