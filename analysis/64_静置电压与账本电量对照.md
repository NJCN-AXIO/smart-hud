# 64 静置电压 vs 账本电量对照（11-20～11-24 两箱电）

## 目的

v1.0.59 之后按用户确认（隔夜没充电；电量口径由数据定）复盘：静置时电压查表（sra）与里程账本（soc）
差多少、底部偏乐观多少，作为下一轮调锚点守卫/电压表的依据。探针：`tools/rest_soc_probe.py`，
过滤条件 sag≤0.6V、spd≤2、thr≤1.5（车停着、没带载）。

## 结论

1. **高段（≥75.5V）表与账本吻合**，满电锚点可信。
2. **中低段（70–73V）账本持续高于电压表 6→16→20 点**，越到底部偏得越多。
   对照第一箱：69.6V/58.7km 时账本 28 ≈ 表 25；第二箱 69.2V/71.2km 账本却有 44 ——
   同样电压、里程更远，账本不该还高一档，说明第二箱**里程口径偏乐观**。
3. 斜率：第二箱 87%@33.25 → 44%@71.2 ≈ 1.13%/km；第一箱整箱 100→9%/70.3km ≈ 1.30%/km。
   学到的 perKm 0.983 略偏缓，但偏差主因不在斜率，而在**静置锚点守卫把电压纠偏挡在了门外**：
   diff >12 判不可信，连拒 3 次后每次只挪 3 点、整箱预算 12 点，20 点的分歧基本拉不回来。
4. 风险边界（v1.0.56 已被单测否掉的老路）：末端塌陷场景 66.2V 静置≈4% 但实际还能骑，
   不能"底部一律信电压"。下一轮若放宽静置纠偏，必须排除空电硬着陆（emptyLatch）之后的回弹段，
   且要有连续多次同向静置 + 长时间稳定电压作前提，不能一次停车就整段跳。
