# v1.0.23：三个面板重做（去掉冗余 + 统一深色面板）

## 一句话

三个按钮打开的界面从"系统弹窗堆控件"改成**底部升起的深色圆角面板**，
每组一个卡片，每个面板只留真正会用的东西；协议调试项全部收进「高级」。

## 具体改了什么

### 1. 电压面板
| 原来 | 现在 |
|---|---|
| 一大段说明 + 上次记录 + 学到的 %/km + 剩余续航 + 输入框 + "我现在是满电"按钮 + "满电续航"输入框 + "按已用电量校准续航"按钮 + 保存/清除/取消 | **三张卡片**：「此刻」（带载 / 静置 / 电量）、「录入」（一个输入框 + 保存）、「自学习」（%/km、满电续航、还能跑，只读） |
| 四件事混在一个窗口 | 这个窗口只干一件事：**录入一个电压**。满电/续航校准搬到设置页 |

### 2. 标记面板
| 原来 | 现在 |
|---|---|
| 为字段求解器服务：±0.1/±1 步进、两排预设电压、7 个速度按钮、还在页面上打各通道 hex | **只保留一个作用**：一键把此刻读数写进日志（电压/静置/电量/里程/时速/整车累计/来源/通道名） |
| 需要你手点十几下才记一条 | 一个按钮，点完自动落一行 `MARK`，我对着截图就能定位同一秒 |

### 3. 设置面板
| 原来（13 个分组，要滚三屏） | 现在（4 张卡片） |
|---|---|
| 界面：Compose 开关、语音播报 | **界面**：语音播报、配色、亮度（配色亮度从"点按钮切下一个"改成**直接点选**） |
| 设备：BLE 引擎北欧库/自写、AE02 订阅、扫描、MAC、名称 | **设备**：连接状态、扫描、MAC、名称、后台常驻 |
| 电压字段（偏移/位宽/大端/系数/偏置）、速度字段、试算、通道候选 | 全部移入「高级 · 协议调试」 |
| 电量模型、电压账本、换电瓶 | **电量**：满电续航、满电/欠压电压、额定电压/容量、整车累计、按已用电量校准、换电瓶 |
| 电池容量、整车累计、防盗、配色亮度、导航、数据 | **数据**：日志说明 + 导出 + 通知使用权 |
| 保存 / 取消 | **保存** + 次级入口「高级（协议调试）」 |

删掉/搬走的都是"协议还没解出来时才需要"的东西：AE02 订阅（实测不影响帧格式）、
Compose 开关（现在只有一套界面）、字段偏移输入、试算按钮。

## 视觉（参考对象）

- **Material 3 深色 BottomSheet**：底部升起、22dp 顶部圆角、抓手条、标题 22sp 粗体 + 12sp 副标题
- **iOS / Material 的分组列表**：每组 12sp 小标题 + 卡片（#141A21，18dp 圆角），行内左侧标签 15sp、右侧值 16sp 粗体
- **DigiHUD / OpenTracks**：主操作一个通栏实心按钮（54dp），次操作描边按钮，触控尺寸远超 48dp 下限
- 配色只三档：主文字 #E9EEF4、次要 #8E9BA8、强调 #35E07A（和 HUD 主色同源）

## 顺手改的

- 底部三按钮 **64 → 72dp**，与手势区留更多间距（之前贴底、单手够不到）
- 「导出原始帧日志（微信/文件传输发出去）」→ **「导出日志（直接发给我）」**
- 「设置」弹窗里的保存逻辑保持原样（改 MAC 重连、改语音重启服务、改整车累计清 App 累计）
