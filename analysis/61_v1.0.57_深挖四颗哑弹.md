# v1.0.57 深挖：四颗埋在代码里的"哑弹"

复盘不是再讲一遍 v1.0.56 修了什么，而是把 5 份日志逐分钟拆开（`tools/deep_probe_1121.py`），
看还有哪些地方在**悄悄吃掉准确性**。查到四条，全部是"规则写得对、但根本没被执行"的类型。

## 一、时速兜底是死代码（里程少记的真凶之一）

`tick()` 里里程积分有两条路：有位移就走位移，没位移就"按速度 × 1 秒"。
第二条问的是 `HudState.speedKmh` —— 它只由 `Reading`（67B 帧）写入，
而**协议里根本没有轮速字段**，所以它恒为 `NaN`。

于是日志里这些场面反复出现：

```
17:09:29 -> 17:11:08 (98 s)   有速度、里程不长
12:12:20 -> 12:16:36 (256 s)  有速度、里程不长
12:20:46 -> 12:28:54 (488 s)  有速度、里程不长
18:07:17 -> 18:09:57 (160 s)  有速度、里程不长
```

`odo blind: spd=26.0km/h but no gps delta for 62s` 就是它的旁证：定位精度超过 50m
（进商场、过桥洞、楼间）时位移被丢，时速还准，里程却整段不涨。一趟 10–15km/h 的市区跑，
这些空档加起来就是 1–2km，正是"本次 69.6 / 仪表 75.5"里那 6km 的一部分。

**改法**：三级回落 `控制器速度 → 显示时速 → 原始滤波时速`；GPS 口径要 ≥4km/h 且持续 4 秒
（停车漂移常见 1–3km/h，不能让它凭空生里程）。盲区里按速度积过的段，位移恢复时只对表不计
（`odoSpeedFill`），避免桥洞那 1km 被算两遍。

## 二、"学斜率"被"跳不跳锚点"连坐

17:38 那条 `soc anchor nudge+0 v=69.6 socV=15 socKm=32 km=58.74 rejects=1`：
电压口径 15%、里程账本 32%，差 17 点 > `maxAnchorJumpPct`(12)，守卫拒了 —— 拒得对，
这台车末端电压会塌陷。但副作用是**"这 32km 到底耗了 1.45%/km"这个证据也被一起扔了**。
perKm 于是永远停在 1.14，底部一路偏乐观。

**改法**：`SocTracker.learnPerKmFromRest()` —— 锚点跳不跳是一回事，斜率学不学是另一回事。
参考点取"上一次被电压确认过的锚点"，要求段 ≥8km、差 ≥5 点，折算满电续航必须落在 45–145km
（这一条专门挡 26.8km 读到 4% 的塌陷，那折算出来只有 28km，直接丢），
一次改动幅度按段长放宽（40km 的段允许 60%，10km 的段只允许 25%）。
学到后顺带把 `est_range` 改成 `100/perKm`（本轮 1.37 → 73km），续航硬顶立刻跟着变紧。

按当时数据重算：`(71−15)/32.16 = 1.74%/km`，与 1.14 加权 0.5 → **1.37%/km**，
真实 1.30%。于是 18:14（69.6km）显示从 **21% / 19km** 变成 **17%**，而续航硬顶 73−75.5 < 0 → **0km**。

## 三、熄火停车时静置校准几乎全灭

`rest cal #1 @120s / #2 @301s / #3 @481s` 后面跟着 `soc calibrate skipped: no settled voltage`，
一天二十多条。原因：骑手停好车就把钥匙拧掉 → 控制器不推帧 → 8 秒后 `restFilter` 被 reset → NaN。

**改法**：断链前把最后一段静置均值存进 `lastRestV`，20 分钟内允许拿它校准，且**只准往下压**
（旧值可能只是带载压降，不能把电量往上抬）。日志会写 `soc stale rest ...`。

## 四、断电那一刻链路正好断掉，空电锁就漏判

18:24 截图：控制器已经拧不动（P档），蓝牙却掉线，屏幕挂着 32 秒前的 68.0V（灰），
`lowVoltWarn` 的判据是 `live && disp < 60.5`，于是根本没触发，电量还写 9%。

**改法**：允许用 120 秒内的最后一次带载电压判 —— 断电保护不会在 2 分钟内自己变好。
触发时日志会标 `(link lost, last live)`。

## 五、顺手补的一致性护栏

续航被 `estRange − kmCharge` 压到 ≤1km 时，账本可能还挂着十几个点，屏幕上就出现
"17% 但 0km"。现在这种情况直接把电量压到 4%、续航 0 —— 电量 / 续航 / 底部提示三处说同一件事。

## 七、还没解决的（写在明处）

- 中段电压平台仍不准，只能靠里程账本；这一版的斜率学习把误差从 ±20 点收到 ±6 点量级。
- 蓝牙会周期性抖动（17:34→18:48 有 74 分钟没有电压帧，那段时间人停车在家，所以不算漏电）。
  `rebuild backoff` 已到 30 分钟封顶，**真机换位/干扰**才需要再动，暂不改逻辑。
- 电池容量 21Ah 还是 20Ah 未确认，只影响能耗展示。
- `est_range` 现在会自动从实测改（73/77 这种），设置页看到它变了是正常现象。
