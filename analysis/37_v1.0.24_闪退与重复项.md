# v1.0.24：修闪退 + 收掉重复项 + 底部那行小字

## 1. 点「电压」闪退 —— 真因

不是布局、不是权限，是**格式化字符串和参数类型不匹配**：

```java
// 分钟数是 long，格式符却是 %.0f
String.format(Locale.US, "… %.0f 分钟前", Math.max(0L, (now - last.ts) / 60000L));
```

`java.util.IllegalFormatConversionException: f != java.lang.Long` —— 弹窗还没显示出来就抛了，
所以表现就是"一点就闪退"。已改成 `%d`。

这类错误编译期查不出来（格式串是运行时解析的），只能靠看代码或看堆栈。

**顺手补了一个"崩溃也落盘"**：装了个默认异常处理器，崩之前把完整堆栈写进
`raw_*.csv`（`CRASH thread=… java.lang.IllegalFormatConversionException …`）。
以后再有闪退，你只要导出日志发我就能定位，不用装 adb、也不用靠回忆点了哪个按钮。

## 3. 底部"语音✓"

它是永久存在的状态徽标：正常时显示"语音✓"，孤零零挂在三个按钮上方，不指路也不报警。
现在：
- **正常就一行不显示**（和"连上控制器就不出状态行"一致）
- 只在**语音开了但没就绪**时出"语音没就绪"（这时才是需要你知道的）
- "链路已优化"这个徽标也一起撤了（同属"一直挂着的状态"，长按状态行仍可看诊断）

## 4. 另外修的两个真问题

| 问题 | 根因 | 修法 |
|---|---|---|
| 大数字显示 `--%`，副标题"按推算电压" | 点过"换了新电瓶"后，只清了内存账本，**没清 SharedPreferences 里的锚点**；于是 bootstrap 认为"已有锚点"不跑，内存账本又没有锚点 → `update()` 一直返回 NaN | 两个账本一起清；并加兜底：只要电压可读就不显示 `--%`，先用电压口径顶上 |
| 设置里"语音播报"文字被挤成竖排 | 复选框走了通用行布局（左侧标签 + 右侧固定 108dp 槽位），长文案只能三四行折行 | 复选框改整行布局，说明文字放它下面一行 |
