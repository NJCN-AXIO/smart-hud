# v1.0.44：那一刻"骑不动"到底是车没电，还是 App 算错

## 一、先对账：电压两边一模一样

| 时刻 | 育宁小程序 | 智能HUD |
|---|---|---|
| 22:43 | 电池电压 **59.5V**、转把 3.5V | 22:44 主屏 **59.5V** |

差 0.0V。这条最要紧：说明"连上就直读"这条路是对的，之前"小程序 68.6 / APP 66.1"的偏差
不是读法问题，是**两边不是同一时刻**（控制器同一时刻只允许一条连接）。

## 二、"没动力"是物理事实，App 报 0% 不冤

同一份日志（`raw_20261118_224404.csv`）里的原话：

```
22:44:07  rv=59.50 v=59.50 vm=64.59 sag=5.09 thr=3.53 spd=23 soc=0
22:44:43  rv=59.66 v=59.66 ...     thr=2.22
22:44:45  rv=59.69 v=59.69 ...     thr=0.76   ← 松油门
22:45:05  rv=59.77 v=59.77 sag≈0.4 spd=12
22:53:xx  rv=64.57（停车静置）
```

- 满油门时端电压 59.5V，压降约 **5.0V** → 开路 64.6V → 查表 **约 3%**；
- 72V 铅酸 6 串的欠压线 63.0V，控制器在 59.5V 时已经在**低压保护**（拧油门不走），
  松油门回 64.5V 也只够"挪几步"。
- 所以"骑不动"不是 App 判断失误，而是这组电瓶真的到底了。

**但界面确实没把这件事说清**——只有电压变红 + 0%，没有一句话解释"为什么拧油门不走"。

## 三、这一版挖出来的 5 个真 BUG

### BUG 1：电量在 0 和 2 之间每两秒跳一次

```
SOC 0 -> 2  vm=64.59 ...
SOC 2 -> 0  vm=62.00 ...
```

不是电压在动（rv 一直 59.5），而是**查表用的 vMap 在切源**：
`ocvCand` 的样本数在阈值 8 附近来回穿，样本足 → 用 64.59（2%）；样本不足 → 退回"本帧+压降"=62.00（0%）。
修法：样本不够时**沿用上一次的 vMap**，不再切回瞬时值；阈值 8→4。

### BUG 2：45 秒窗"换气"导致 4 秒掉 11 分

`raw_20261118_200840.csv`：电压 72.76→72.92 几乎没动，屏幕 75 → 69 → 64。
这是滚动窗口的固有行为（旧的高载样本同时过期）。6 秒中位数压得住单帧，压不住整窗换气。
修法：在输出端加**显示层**（下面的 `SocDisplay`）。

### BUG 3：断开后把"冻结读数"标成"推算"

22:53 起 `v=- src=3 soc=2`，界面按 SRC_EST 写"控制器未连接 · 电压为推算值"。
实际这是**断开前最后一帧真读到的数**，说成"推算"会让人以为在猜。
修法：新增 `SRC_FROZEN`，文案改成"控制器未连接 · 显示断开前读数 8 分钟前"。

### BUG 4：断开后日志还在写 `rv=64.57`

链路断了 10 分钟，`lastRawV` 一直停在最后一帧，REC 每 2 秒照抄一遍 —— 复盘时会误以为"还在读、只是没上屏"。
修法：`rv` 只在有帧（8 秒内）时写，否则写 `-`。

### BUG 5：低电量提醒的日志是 `v=NaN`

`low power alert: soc=0 v=NaN` —— 那一刻其实有电压（59.5），只是传进来的是空值。修掉格式化。

## 四、新增：电量显示层（死区 + 限速 + 重连直跳）

数学在 `:core.SocDisplay`，上游仍然是"这一帧电压查出来的真值"，只做**显示整形**：

| 规则 | 参数 | 作用 |
|---|---|---|
| 死区 | 2 分 | 目标与显示差 ≤2 分就不动 → 0↔2 这种抖动彻底消失 |
| 限速 | 降 2 分/秒、升 2 分/秒 | 一段 11 分的变化摊成 5–6 秒平滑下滑 |
| 重连直跳 | 断档 >60 秒且差 ≥20 分 | 充完电 2%→100% 直接落位，不做假爬坡 |

**实测重放**（拿历史日志的 `vm` 逐拍喂进去，`tools/replay_soc.py`）：

| 日志 | 旧（仅 6 秒中位数） | 新（+ 死区 + 限速） |
|---|---|---|
| `raw_20261118_200840.csv`（骑行 40 分钟） | **22 次** ≥5 分跳变 | **2 次**（都是重连直跳） |
| `raw_20261118_224404.csv`（没电那段） | 0 次（一直卡在 0/2 抖） | 0 次，稳定在 2 |

## 五、新增：欠压保护提示

电压低于设置里的欠压线（默认 63.0V）且有帧时，状态行直接写：

> 已低于欠压线 63V · 控制器在低压保护（拧油门不走是正常的）

这样"骑不动"这件事从"猜"变成"写着"。松油门回压到欠压线以上，提示自动消失。

## 七、下次实测看点

1. 停一晚再骑：早上第一次连上应**直跳**到真实电量（不再从 2% 慢慢爬）。
2. 骑行中盯着电量：应当是"每几秒掉 1"，不再出现两位数跳。
3. 骑到没电：应出现"已低于欠压线 63V · 控制器在低压保护"，而不是只有红色 0%。
4. 拔掉/走开（断开控制器）：状态行应是"显示断开前读数 X 分钟前"，电压 `--.-`、电量保留断开前那个数。
