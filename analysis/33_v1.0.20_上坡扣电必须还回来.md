# v1.0.20：上坡扣掉的电，松油门必须还回来

你这句话是这轮最关键的定位：**"上坡满油门电压掉 → 续航算小了；平路松油门电压回升 → 续航没跟着回来"。**

这不是"算得不准"的问题，是一条**单向的账**：我们的电量只会往下走，不会往回涨。
所以每爬一次坡，电量就被永久扣掉一截 —— 跑一天下来，"还能跑"越来越短，跟真实电量脱节。

## 一、为什么会这样（三处叠加）

| 环节 | 旧行为 | 后果 |
|---|---|---|
| 压降补偿 | 只按**速度**补：`0.06V/(km/h)`，封顶 2.6V | 上坡 15km/h 满油门，实际压降 5–8V，只补 0.9V，**剩下 4–7V 被当成"电掉了"** |
| 行驶中电压纠偏 | 只要里程在涨就参与，**不看负载** | 爬坡那几秒把电量往下拽（一次 3 点，一箱电 12 点预算） |
| 回升 | **完全没有**：纠偏只降不升 | 松油门后电压回到 OCV，电量却停在低位，续航跟着少一截 |

三条串起来就是你看到的现象：**爬坡扣电、平路不还。**

## 二、这版怎么改（三处，一一对应）

### 1. 压降补偿改成"按油门算"，不再只看速度

转把电压（协议里的 `0.019 × f[42]`）本来就是**油门开度的直接代理**：怠速 0.8V，拧到底约 4.0–4.3V。
所以：

```
sag = min(2.6V, 0.06 × 速度) + min(7V, 1.2 × (转把 − 0.8V))
```

实测算例：

| 场景 | 旧补偿 | 新补偿 |
|---|---|---|
| 平路 30km/h、松油门 | 1.8V | 1.8V（不变，本来就准） |
| **上坡 15km/h、油门到底** | **0.9V** | **4.98V** |
| 停车、油门回位 | 0 | 0（仍是真实静置电压） |

物理上更对：**压降 ∝ 电流 ∝ 油门**，跟速度只是间接关系。

### 2. 明显在出力时，不许拿电压往下拽电量

```
转把 − 0.8V > 1.2V  →  判定"在出力" → 跳过这次电压纠偏（只记日志）
```

这样爬坡那几秒电压再低，也不会把电量按下去。等松油门、滑行、停车再让电压参与。

另外修了一个隐藏坑：**转把值只对"3 秒内到过帧"可信**。链路断开后它会停在最后一帧（可能是满油门 4V），
拿它当"正在出力"会永久挡住纠偏 —— 现在会判为无效。

### 3. 新增"电量回升"：松油门后把欠的还回来

`SocTracker.recoverUp()`，四道门槛，都为了不来回打摆：

| 条件 | 值 | 理由 |
|---|---|---|
| 电压口径比显示值高 | ≥ 4 点 | 小于 4 点当作噪声，不动 |
| 且连续维持 | 45 秒 | 一瞬间的电压尖峰不算数 |
| 每次最多涨 | 1 点 | 慢慢还，不跳 |
| 每涨一次后重新等 | 45 秒 | 不许 5 秒一档往上冲 |
| 一箱电总回升上限 | 10 点 | 防止把电量抬虚 |

也就是说：爬坡扣掉的 3–5 点，在平路上大约 2–4 分钟内会**逐步补回来**，而且绝不会超过真实值
（因为还受"电压口径"和"10 点预算"双重约束）。

## 三、改完之后的预期行为

| 场景 | 电量显示 |
|---|---|
| 满电出发 | 100% |
| 爬一个长坡（油门到底） | **几乎不动**（电压低但被判定为"带载"，不参与） |
| 到坡顶松油门滑行 | 若电压口径更高，1–4 分钟内**逐点回升**（最多 10 点） |
| 平路正常骑 | 按里程 + 电压双向微调，一天下来不再"越骑越虚" |
| 真的快没电 | 电压持续偏低、能量也用掉大半 → 回升条件不满足 → 电量照常往下走（不会骗你） |

日志里能直接看到两端：
- `soc fuse skipped: under load (thr=4.1V sag=5.0V ...)` —— 爬坡时它没动手
- `soc recovered +1.0 -> 63 (volt=64 thr=0.9 ...)` —— 松油门后还回来了

## 五、上车怎么验（这次很好验）

1. 找一个**明显上坡**，油门拧到底骑上去 → 电量**应该几乎不跳**（旧版会掉几档）。
2. 到坡顶**松油门滑行 2–4 分钟** → 电量应该**逐点回升**，最多回 10 点。
3. 回看日志：上坡段落应有 `soc fuse skipped: under load`，松油门段落应有 `soc recovered +1.0`。

如果第 1 步还是在掉，说明这台车的实际压降比 1.2V/油门更大 —— 那时候把日志给我，
我按实测把系数调上去（这个系数本来就该由数据来定，不该我拍）。
