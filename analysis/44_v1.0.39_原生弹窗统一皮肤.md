# v1.0.39：把最后三处系统原生弹窗换成同一套皮肤

## 现状盘点

三个面板（电压 / 标记 / 设置 / 协议调试）v1.0.23 起已经走 `PanelUi`：深色底部面板、抓手、
卡片分组、绿色主按钮。**漏掉的是三个"只读一段话 + 点按钮"的小弹窗**，它们一直用系统的
`AlertDialog.Builder`：

| 位置 | 场景 | 原来长什么样 |
|---|---|---|
| `maybeShowFirstRunTip` | 首次上车引导 | 系统白/灰底、方角、标题黑体、按钮是系统蓝字 |
| `showDevicePicker` | 扫到设备后的选择列表 | 系统 AlertDialog + 一堆裸 `Button`（灰底圆角、文字居中、12sp） |
| `onLongPressReset` | 长按本次里程 → 本次骑行统计 | 同一套系统皮，和旁边的深色面板并排看非常割裂 |

系统 AlertDialog 跟随的是 App 的 `Theme.Material.NoActionBar`，不是我们的深色 HUD 配色，
所以它们在 HUD 上会突然"变亮"——这就是"部分界面还是原生安卓界面"的来源。

## 做法

不给系统 AlertDialog 打补丁（换 theme 只能改颜色，改不了它那套标题/按钮布局），而是让 `PanelUi`
多一种形态：**居中小卡片**，与已有的底部面板共用同一份设计常量（`BG/CARD/FIELD/LINE/TXT/SUB/ACC`
、22dp 圆角、52dp 触控高度、绿色实心主按钮 + 描边次按钮）。

`PanelUi` 新增：
- `card(activity, title, subtitle)` — 居中小卡片，带底部按钮区
- `cardBare(...)` — 同上但不要底部按钮区
- `cardTall(..., fillFrac)` — 撑到屏幕固定比例、内部滚动（设备列表这种不定长的用 0.62）
- `body(text)` — 正文块（15sp、行距 1.25）
- `listItem(text, onClick)` / `hintLine(text)` / `clearContent()`

三处替换后：

- **首次引导**：`card` + `body`，主按钮「知道了」、次按钮「现在扫描」。
  顺便把文案改成当前的行为（原来还写着"填入候选映射""满电改成 78.0"，那些是 v1.0.30 之前
  的临时口径，现在直读电压、不需要任何标定，留着会误导）。
- **设备选择**：`cardTall(0.62)`，表头 12sp 灰字，每台设备一行 52dp 描边按钮（左对齐、
  MAC + RSSI 同排），点了就连、连上自动关卡片；列表仍每 0.7 秒重建。
- **本次骑行**：`card` + `body`，主按钮「清零本次里程」、次按钮「取消」。

Toast 保留系统样式——那是跨 App 一致的短提示，不属于界面皮肤。

- `self_check` 6 项全过；APK = 76 / 1.0.39。

## 上车看点

1. 第一次装（或清除数据后）打开 → 引导卡片应该是深色圆角、绿色「知道了」，不再是白底蓝字。
2. 点「现在扫描」→ 列表是深色卡片，每台设备一行描边按钮，间距 8dp、高度够拇指点。
3. 长按主屏「本次里程」→ 统计卡片同款皮肤，底部绿色「清零本次里程」+ 描边「取消」。
