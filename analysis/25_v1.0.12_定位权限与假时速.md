# v1.0.12：定位权限缺失（可能是"不够准"的上游原因）+ GPS 断流假时速

这轮换了个方法：不再只靠人眼读代码，改用 **Android Lint**（Google 官方静态分析，
和社区里做 Android 项目的做法一样）把整个工程扫一遍。它一次报出 6 个 error、
38 个 warning。逐个查下去，其中两个是真的会影响车上的表现。

## 1. 🔴 只声明了 FINE，没声明 COARSE —— 时速/里程可能从源头就是垃圾

Lint：`CoarseFineLocation: If you need access to FINE location, you must request both ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION`

代码里是这样：

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```

Android 12+ 的规则是：**应用可以只拿到"大致位置"**（用户可以在弹窗里选"仅大致"），
而这套降级路径要求应用**同时声明** COARSE。只声明 FINE 时，不同 ROM 的行为不一样：

- 有的机型只给"大致位置"（Cell/WiFi 定位，精度 500–2000m）
- 有的机型直接拒掉

**后果**：`TrackDistance` 的精度闸门会把这些点全部丢掉（精度差于 10m 就不要），
或者用几百米误差的点算距离 —— 时速和里程会系统性失真，而 HUD 上看不出任何异常。
这很可能就是"时速不够准、里程和电量对不上"的最上游那条。

**修法**
1. Manifest 同时声明 COARSE + FINE。
2. `ensurePermissions()` 两个都请求（这是 Android 官方要求的写法）。
3. **把权限问题写到屏幕上**（新增 `HudState.gpsWarn`）：
   - 只有大致位置 → 「定位只有"大致位置"→ 时速/里程会失真，请在系统设置里改成"精确位置"」
   - 完全拒绝 → 「没给定位权限 → 里程和时速不可用」
   - 系统定位开关没开 → 「系统定位开关没开 → …」
   这三种以前只写进日志，屏幕上是两个 `--` 和一根不动的里程，骑手只会觉得"坏了"。

## 2. 🟠 GPS 断流后，时速永远卡在旧值

`HudState.gpsKmh` 只在**收到定位回调**时才更新。也就是说：

- 进隧道 / 地下车库 / 商场内部 → 没有新定位 → 屏幕上一直显示"32 km/h"
- 系统掐掉定位（省电策略）/ 权限被撤回 → 同上

电压有 8 秒过期保护（v1.0.1 就做了），**时速完全没有**。
骑手看到的是一个"车还在跑"的假象，比显示 `--` 危险得多。

**修法**：记录最后一次真正收到定位的时刻 `lastGpsFixWall`，tick 里超过 **8 秒**没新定位就把
`speedStab.reset()` + `HudState.gpsKmh = NaN`，并写日志
`gps speed stale > 8s, dropped (last fix Ns ago)`。恢复定位后重新出现（不会继承旧的速度平滑状态）。

## 3. 🟠 广播注册写法在部分机型会崩

`if (SDK_INT >= 33) registerReceiver(rx, f, RECEIVER_NOT_EXPORTED) else registerReceiver(rx, f)`
—— 33+ 上某些 ROM 会抛
`IllegalArgumentException: One of RECEIVER_EXPORTED or RECEIVER_NOT_EXPORTED should be specified`。
已改成 `ContextCompat.registerReceiver(..., RECEIVER_NOT_EXPORTED)`（官方推荐写法，低版本自动降级）。

## 4. 🟡 4 处 GPS 调用没有显式权限判断

`requestLocationUpdates` / `getLastKnownLocation` 虽然外面有 `try/catch(Exception)`，
但静态分析看不到这条保护。已给每一处加上**内联的 `checkSelfPermission` 判断**
（用内联而不是自定义 `hasPerm()`，是为了让静态分析也能看懂）。

## 5. 🟡 `Prefs.setMac` 用了默认 Locale

`toUpperCase()` 不指定 Locale：土耳其语环境下 `i` 会变成 `İ`，MAC 里出现这种字符就连不上。
已改成 `toUpperCase(Locale.ROOT)`。

## 静态分析结果

| 指标 | 修前 | 修后 |
|---|---|---|
| Lint **errors** | 6 | **0** |
| Lint warnings | 38 | 37 |

剩余 37 条 warning 全部是"不影响运行"的类型：`SDK_INT` 冗余判断（minSdk 26 后不需要）、
中文硬编码文案（本项目不做国际化）、竖屏锁定（HUD 必须竖屏）、`allowBackup` 建议、
自绘 View 的 `onTouchEvent` 未实现 `performClick`。逐条判断过，**不改**。

## 车上怎么验（这版最该验的一条）
1. 打开 App 时如果弹权限框，**必须选"精确位置"**（选"大致"会看到屏幕下方那句提醒）。
2. 去系统设置确认：设置 › 应用 › Delivery HUD › 权限 › 位置 = **精确**。
3. 骑一段再看里程：如果之前里程偏少/时速跳动明显，这一版应当有可见改善。
4. 进一次隧道或地下车库：时速应当变成 `--`（而不是卡在 30 多），出来立刻恢复。
