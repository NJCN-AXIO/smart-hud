# v1.0.2 状态栏回归 + 小米焦点通知/超级岛接入

日期：2026-11-17　版本：1.0.2 (versionCode 39)

## 一、这轮改了什么

### 1. 不再沉浸式全屏，顶部状态栏回来
- `MainActivity.goFullscreen()` → `showSystemBars()`
- 关键点：`Window.setDecorFitsSystemWindows(true)`。上一版是 `false` + `hide(systemBars())`，
  内容会铺到状态栏底下；现在让系统栏正常占位，Compose 的内容区自动让出状态栏高度，
  不会出现"三个大数字被状态栏压住"。
- 颜色：状态栏 / 导航栏都设成 `#07090C`（和 HUD 背景同色），图标用浅色
  （`APPEARANCE_LIGHT_STATUS_BARS` 传 0 = 不要深色图标，否则黑底黑字看不见）。
- 防误触不再依赖隐藏系统栏，靠底部三按钮条 + 长按（原有逻辑不变）。
- 三个数字所在的 `Column` 是 `weight(1f)`，状态栏吃掉约 25–30dp 后仍是一屏铺满，不会溢出。

### 2. 焦点通知 / 超级岛（`FocusIsland.java`）
小米官方《超级岛开发指南》的**客户端实现**路径，和推送通道无关：

```
正常发一条原生常驻通知
  → notification.extras.putString("miui.focus.param", json)
  → 系统支持且本应用有权限：显示成状态栏焦点通知（OS2）/ 超级岛（OS3）
  → 没权限：按普通通知显示（官方 filterWhenNoPermission 默认 false，不会把通知过滤掉）
```

代码落点：
- `FocusIsland.protocol(ctx)`：读 `Settings.System.getInt("notification_focus_protocol", 0)`，
  1=OS1、2=OS2、3=OS3（**只有 OS3 才有"岛"**）。
- `FocusIsland.hasPermission(ctx)`：`content://miui.statusbar.notification.public` 的
  `canShowFocus`，耗时调用，只在启动时查一次并写进日志。
- `FocusIsland.attach(...)`：拼 `param_v2`
  - 公共：`protocol=1`、`business="ebike"`、`updatable=true`、`enableFloat=false`（更新时不弹开，
    骑车挡视线）、`ticker`（OS2 状态栏那行）、`aodTitle`（息屏文案）
  - 焦点通知本体：`baseInfo{title: "电量 65%", content: "72.3V · 12.4km · 还能 43km",
    colorTitle: "#3ADE71", type: 2}`
  - 仅 `ver>=3` 才塞 `param_island{islandProperty:1, bigIslandArea{imageTextInfoLeft{type:1,
    textInfo{frontTitle,title,content,useHighLight}}}, smallIslandArea{textInfo}}`
    —— 图必须走 `miui.focus.pic_*` 的 Icon 资源，这里没有合适图标，宁可不传，纯文本最小集。

- 通道：新建 `CH_FOCUS = "hud_focus"`，`IMPORTANCE_DEFAULT`（**LOW 通道系统不会抬成焦点通知**），
  `setSound(null)` + `enableVibration(false)` + `setShowBadge(false)` + `VISIBILITY_PUBLIC`；
  通知侧 `setSound(null)/setVibrate(null)/setDefaults(0)/setOnlyAlertOnce(true)/setShowWhen(false)`，
  所以"级别够但不响不亮"。
- 通知头改成"电量 65%"，正文仍是 `电压 · 电量 · 里程 · 时速`（`statusLine()`），
  点通知直接回 HUD（`openIntent()`，`FLAG_IMMUTABLE`）。

## 二、必须在真机上确认的两件事

1. **本机是不是 OS3**。启动后 CSV 里会有一行：
   `focus island: OS3(超级岛) perm=false`（或 `OS2(焦点通知)` / `不支持`）。
   - 红米 K80 出厂是 HyperOS 2，若已升到 HyperOS 3，`protocol=3` 才有岛；
   - 若仍是 OS2，只能出**状态栏焦点通知**（顶部一行 `72.3V · 65%`），不会上岛。
2. **焦点通知权限是白名单**。没有权限时 `miui.focus.param` 会被系统忽略，退化成普通通知
   （这一点官方写明默认不过滤，所以功能不会坏，只是不上岛）。
   申请方式：邮件 `mipush-permission@xiaomi.com`，主题
   `【申请开通小米焦点通知使用权限】-yymmdd-「Delivery HUD」`，正文要给：
   应用名称/包名(`com.hud.delivery`)/appid、channel_id(`hud_focus`)、公司主体、对接人、联系方式、
   申请内容（实时更新类：骑行中常驻显示电压/电量/里程，刷新 5s，随骑行结束消失）、
   效果图与交互说明、使用声明。

> 结论：**不上岛也能用**，状态栏那行和通知栏内容已经按"骑行数据"重排了；
> 上岛只差系统版本 + 一行权限。
