# 14｜电量口径重做：静置锚点 + 里程推算（v1.0.0）

这轮针对 2026-11-17 夜里的实际反馈（日志 19:51–22:15 共 12 个 CSV + 截图）：

- 小程序 68.6V，App 66.1V
- 同一时间点电量从 51% 跳到 17%
- 26.8km / 4% / 还能跑 ~1km
- 要求彻底删掉演示模式

## 一、先把"电压对不上"这件事查清楚

### 证据 1：控制器这一路电压本身就是噪声

用 22:12:45–22:15:27 那段日志（313 帧）按小程序公式解出来：

```
raw    mean=65.15  median=65.52  min=58.26  max=69.19
```

同一分钟内，端电压在 **58.26–69.19V** 之间跳 ±5V。
再看 `analysis/volt_fields_221245.txt` 里的原始字节：f[63]（高字节）在 24–26 之间慢慢走，
f[64] 却在 +182 和 −62 之间来回跳——**低字节是噪声**，但小程序就是用
`(256*f[63]+f[64])/100` 显示，所以小程序自己的数字也在跳。

结论：**不是我们解错公式**（公式和小程序逐字一致），而是这个字段是"瞬时采样"，
没有做滤波。我们旧版用 4 秒滑动平均，平均会被 58V 这种离群值拖低，
所以截图那一刻显示 62.5V，而小程序那一刻正好抽到 68.6V —— **两边读的是同一串噪声，只是抽到的样本不同**。

### 证据 2：电量在 3 分钟里 5% ↔ 7% ↔ 4%

22:12 那段的 state 行：

```
state v=66.1 src=1 soc=6  ocv=67.3 sag=1.8
state v=63.9 src=1 soc=5  ocv=67.0 sag=1.5
state v=64.9 src=1 soc=3  ocv=65.0 sag=1.5
state v=63.8 src=1 soc=7  ocv=67.8 sag=1.5
state v=68.3 src=1 soc=4  ocv=65.8 sag=1.5
```

电量一直是"当前这一帧电压查表"的结果，所以电压抖 5V，电量就抖 4 个点；
用户看到的"51 跳到 17"是同一套逻辑在更大的噪声下发生的。

### 证据 3：26.8km 只剩 4% 是两件事叠出来的

- 电压查表：66V 落在表尾（69.6V→10%，63V→0%），直接算出 5%
- 剩余续航：`电量% ÷ 每公里耗电%`，而 %/km 学到了很差的值（锚点被中途重设），
  于是一边"5%"一边"1.2%/km"算出 1km

也就是说：**不是里程算错，是电量先错了，续航跟着错。**

## 二、新口径（v1.0.0）

### 电压显示

`VoltFilter`：9 点中位数（≈4.5 秒）上屏，替代 4 秒滑动平均。

用同一段日志回放：

```
shown mean=65.31  median=65.36  min=58.55  max=68.43
相邻采样变化  p50=0.02V  p90=0.59V  max=3.35V
```

中位数把"单个离群值"直接丢掉，显示值稳定得多；但它**不可能和某一瞬间的小程序数字逐位相同**——
因为那个字段本身每次采样都在跳。要比就比"停车静置后的读数"。

### 电量：停车量电压，骑行数里程

`SocTracker`（`:core`，纯 JVM，11 条单测）：

1. **停车静置校准**：停稳 60 秒（`enterParked`）时，用 30 秒静置均值查表得到的电量
   作为锚点 `(电量%, 里程km)`，落盘。
2. **骑行按里程推算**：`电量 = 锚点电量 − 每公里耗电% × 里程增量`。
3. **学每公里耗电%**：两次静置锚点之间（≥2km、电量掉 ≥1%）用 Δ电量/Δ里程 学习，EMA 平滑，
   夹在 0.2–3.0 %/km。跑得越多越准。
4. **显示限速**：每秒最多变 2%，任何来源的跳变都不会让数字闪。
5. **满电自动锚 100%**（沿用满电锚点判定），早上充满出门不会还显示昨天的 40%。
6. **锚点 18 小时后作废**：中间可能充过电，不能拿旧锚点硬算。
7. **新装/清数据**：中位数收敛后先落一个临时锚点，等第一次停车再校准。

剩余续航 = `当前电量% ÷ 每公里耗电%`，并限制在满电续航的 1.2 倍以内。

### 界面文案

- 电量副标题：`停车静置校准 · 行驶中按里程推算`（有锚点时）
- 没锚点：`按实测电压估算 · 停车自动校准`
- 电压大字不再标"含压降补偿"——显示的就是实测值（中位数）

## 五、实车要验的四件事

1. 停车 1 分钟后，电量应该跳到"静置电压对应的值"（例如 71.4V ≈ 40%），且之后不再大幅跳
2. 骑 10km 电量应平滑下降（约 12 个点），不会出现 51→17
3. 26km 左右不该出现"4% / 还能跑 1km"
4. 满电出门（78V 左右停车）应显示 100%

日志里会多出两类行，事后可核对：
`soc anchored at rest v=71.4 soc=40 km=12.3` / `soc anchor learned 1.25%/km`。
