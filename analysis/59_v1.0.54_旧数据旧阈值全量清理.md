# v1.0.54：全 App「旧数据 / 旧阈值 / 旧文案」清理清单

起因：v1.0.53 把电量与里程的**两端基准**（76.5/63.0 → 78.6/63.8）、压降模型、里程记录方式全换了，
但设置页、主屏副标题、通知与提醒里还留着大量按**旧口径**写的字和按旧口径学出来的数。
用户的原话是「设置里面还有很多数据是旧的没更新」。

这一版只做一件事：**把旧口径的残留一次清干净**，让界面上每一个数字都能对上现在的算法。

---

## 一、最要紧的一类：按旧表学出来的数（不清掉，改了算法也不生效）

这些数不是"文案"，是**数据**，存在 SharedPreferences 里，以前每一趟都在按 76.5/63.0 那张表
往上累加。表换了以后它们全都偏了，而且程序会拿它们当起点继续算 —— 表现出来就是
"电量算法明明改了，屏幕上还是老结论"。

| 键 | 是什么 | 旧口径下学到的东西 | 处理 |
|---|---|---|---|
| `per_km_pct` | 每公里耗电 % | 按 76.5→63.0 的 100% 跨度标定 | 置 NaN（未标定） |
| `socperkm` / `socperkm_n` | 每公里耗电的平滑值 / 样本数 | 同上 | 清零重学 |
| `vbook` | 电压账本（OCV ↔ SOC 对照） | 整张表按旧基准建的 | 清空 |
| `soc_anchor_soc/km/ts` | 电量锚点（静置校准点） | 旧表查出来的 SOC | 删键 |
| `charge_soc` / `charge_odo_km` | 本箱电起算点 | 旧表口径 | 删键 |

实现：`Prefs.migrateCaliber153()`，一次性 flag `mig_caliber_153`，在 `migrate()` 里排在
`migrateVFull786()` **之后**（顺序不能反：先把基准改对，再清按旧基准学的成果）。

## 三、阈值：写死的老数字（这次最容易被看出来"不对"的）

### 1. 电量副标题：`电压直读` → 说清是哪种口径

v1.0.53 起，**骑行中电量已经不拿电压算了**（电压被压降打乱，见 analysis/57），走的是里程账本。
可副标题还写着"电压直读"，骑手看到"停下 65%、骑起来 71%"自然以为坏了。
现在按 `HudState.socAtRest` 分两种写法：

- 停稳（≥20 秒、速 ≤2、无油门）→ `停稳 · 按电压查表`
- 骑行 → `骑行 · 按里程推算`
- 极简模式同理：`停稳 · 按电压` / `骑行 · 按里程`

### 2. 低电震动 / 语音提醒：66.8V 就震 → 62.8V 才震

`maybeLowPowerAlert` 原来是 `v < vEmpty + 3`。`vEmpty` 现在是**静置**口径 63.8，
而提醒时拿到的是**带载**端电压 → 66.8V 就震，那时其实还有 15~20%，一路被震到真没电。
改成 `vEmpty − 4 + 3 = 62.8`。

### 3. 电压着色：66.8V 标红 → 62.8V 才红

`HudScreen.voltageColor` 同样吃了"静置口径当带载用"的亏。基线改为 `vEmpty − 4`：
红 < 62.8V、黄 < 65.8V。

### 4. 时速着色：25/35 写死 → 跟「超速提醒」走

25 黄 / 35 红是**电动自行车国标线**，这台 72V 电摩实测能上 50，设置里阈值也能改到 50 —— 两边早就不一致。
现在：> 阈值红、≥ 阈值 85% 黄；阈值为 0（关掉）才退回 25/35。阈值由服务每拍同步到 `HudState.speedLimitKmh`。

### 5. `HudState.vEmpty` 初值 63.0 → 63.8

服务没起来时界面也拿它算颜色，初值必须跟新口径一致。

## 四、新增：把"里程记没记全"摆到界面上

设置·运行状态新增一行「**里程盲区**」：

- `0 次 ✅ 全程都在记`
- `N 次 ⚠ 有速度没位移，那几段没记上`

数据来自 `HudState.odoBlind`（服务里每次进"有速度没位移"分支 +1，日志里对应 `odo blind`）。
以后判断"这趟漏没漏"，截图这一行就够，不用翻 CSV。

另外设置·电量加了一段人话说明：

> 电量怎么算：停稳 ≥20 秒 → 按电压查表（这时最准）；骑行中 → 按「这一箱电跑了多少 km」推算，
> 电压不参与。两个口径切换时最多纠 5 个百分点。

---

## 五、故意没动的

- `tripColor` 的 50/60km 黄红：那是"一箱电能跑 80km，跑过 60 提醒你该回电"的经验值，
  与电压口径无关，保留。
- `estRangeKm` 默认 80：实测可用 ~81km，差 1km 不值得改，等你哪天想改再说。
- 「超速提醒」默认 30：这是**你设的**，不是程序写死的；如果你平时就跑 40~45，
  建议改成 45~50，否则整趟屏幕都是红的。

---

## 六、验收要点（装机后看这三处）

1. 设置 → 电量：满电静置电压显示 **78.6**、耗尽静置电压 **63.8**、容量那行的 Wh 跟着你填的 V/Ah 变。
2. 主屏电量副标题：停着显示"停稳 · 按电压查表"，一骑起来变"骑行 · 按里程推算"。
3. 设置 → 运行状态：多出「里程盲区」一行；骑一趟回来仍是 `0 次` 就说明这趟没漏记。
