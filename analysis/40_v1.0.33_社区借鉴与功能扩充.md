# v1.0.33：照社区成熟项目加功能（不加硬件、不改控制器）

本轮目标：**功能更丰富、界面更丰富**，但依然守住三条红线——不买配件、不动手接线、不向控制器写任何数据包（唯一写仍是 CCCD `01 00`）。

## 一、先去看了成熟项目在做什么

| 项目 | 它有的、我们原来没有的 |
|---|---|
| DigiHUD（Google Play 老牌 HUD） | **Lite Mode**（只显示速度）、**HUD 镜面模式**（靠挡风玻璃反射看）、warning speed（超速变红 + 提示音）、Statistics（里程/最高/均速） |
| Speedo360 | 两页滑动切换、触控锁、骑行结果卡分享 |
| Simple Speedometer | **GPS 精度灯**（绿/黄/橙）、行程自动记录、CSV/GPX 导出 |
| BikeTrackd | Compose + Material3、防烧屏、字号可调 |
| M365 Rokid HUD | RSSI 连接质量、遥测导出、后台保活引导 |

筛完之后，只挑**不需要任何新增传感器、也不碰控制器**的四项落地，其余（触控锁、分享卡片、GPX、保养提醒）留到后面按需加。

## 二、这版真正加进去的

### 1. 极简模式（DigiHUD Lite Mode）
- 主屏**左右滑动**（超过 60dp 才算，防止骑车蹭一下就换版式）即可切换。
- 只留两个超大数字：**时速（GPS）** 与 **电量 %**，字号吃满半屏。
- 强光、下雨、戴手套的时候，三个数字反而看不清——这正是 DigiHUD 做 Lite Mode 的理由。
- 极简模式下右上角那个小时速自动隐藏，避免同屏两个时速打架。
- 状态记进设置，进程被杀重启后仍是极简。

### 2. 镜像显示（DigiHUD HUD Mode）
- 设置里「镜像显示（夜间放仪表台靠玻璃反射）」。
- **只翻转数字区**（`graphicsLayer scaleY=-1`），底部三个按钮和状态行保持正向：反射的时候按钮在远处根本不看，但手要能按得着。
- 白天别开（设置里也写了这句）。

### 3. GPS 信号灯（Simple Speedometer 的卫星质量指示）
- 顶部连接文字前一个 7dp 圆点：
  - **绿**：有定位，时速可信；
  - **黄**：有帧但还没定位（刚开机 / 进隧道），时速显示 `--`；
  - **红**：`gpsWarn` 非空（没权限 / 定位被关）。
- 以前要靠读那行小字才知道"这个时速能不能信"，现在一眼就行。

### 4. 超速提醒（DigiHUD warning speed）
- 设置里「超速提醒 (km/h)」，默认 30，0 = 关闭。
- 超过阈值 +2 才触发（避免在阈值上下抖），**60 秒最多喊一次**，用手机自带 TTS，不联网。
- 落日志 `speed warn: xx > limit nn`，方便事后核对是不是真的超了。

### 5. 手机电量提示（附赠）
- 每 30 秒读一次手机电量，只在 **1–25%** 时在状态行显示「手机 23%」。
- 理由很实际：骑手最怕的不是车没电，是**手机先没电、HUD 直接黑屏**，那才是真的瞎跑。

## 三、这版顺手修/确认的点

- 镜像模式一开始是整屏翻转（含按钮条），实测思考后发现按钮会翻到反方向、不好按，改成只翻数字区。
- `detectHorizontalDragGestures` 必须显式传 `onHorizontalDrag`，且要自己累加位移做阈值——不用系统默认的"松手就触发"，否则轻轻一划就切版。
- `Modifier.size` 缺 import 编不过（已补 `androidx.compose.foundation.layout.size`）。
- 界面模式在 `MainActivity.onCreate` 与 `BleService.onCreate` 两处都从设置恢复，避免"服务还没起来时闪回默认布局"。

## 五、留给下一版的候选（都不需要买硬件）

1. 触控锁（长按 2 秒解锁，防骑行误触）——Speedo360 的做法。
2. 本次骑行小结卡（时长 / 均速 / 最高 / 耗电 / 每公里耗电）+ 一键分享文字。
3. 极简模式下的"大电量条"（横向进度条，比数字更快扫一眼）。
4. 夜间自动进极简模式（按亮度或时间段），省得手动滑。
