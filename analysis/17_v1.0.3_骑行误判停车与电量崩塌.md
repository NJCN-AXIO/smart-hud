# v1.0.3 第七轮复盘：找到"26.8km 只剩 4%"的真凶（骑行为被当成停车）

日期：2026-11-18　版本：1.0.3 (versionCode 40)

## 一、先做了一次"字段穷举"，确认精度天花板

新脚本 `tools/byte_field_probe.py`：把 12 份日志共 3820 帧的 67B 逐字节解开，
统计每个 index 的取值个数、范围，以及和（速度、电压 sag）的相关性。


**结论：67B 里没有电流、没有剩余容量、没有轮速字段。** 全帧只有 6 个字节在变，
其中能用的就是电压、转把、故障。所以"库仑计"这条路物理上走不通（这也是之前
13 轮一直用"电压锚点 + 里程推算"的原因）。精度只能靠口径和状态机，不是靠找新字段。

## 二、真凶：状态机把"骑行"判成了"停车"

把 12 份日志的 `state` 行按时间排出来，问题一眼就看得见：

```

v=69.6 soc=58 km=19.35 spd=NaN gkm=0.26   ← 又长 0.18km（≈22km/h）

```

两个特征同时出现：

1. `spd=NaN`，但 `gkm` 每 30 秒长 0.08–0.25km —— **车在 20–30km/h 跑，只是 GPS 速度没给出来**
   （部分机型/室内起点 `hasSpeed()=false`，速度精度判不合格时我们也会主动丢掉这个值）。
2. 电量在这段时间里不是"按里程慢慢降"，而是**每 30 秒往下跳 3–11 点** —— 这是
   `calibrateSocAtRest` 在拿**带载电压**当静置电压做锚点。

链条是：`updateStationary` 只看 `speedStabilizer` 的时速和两点位移（8m<15m 门槛），
速度 NaN 时它认为"停着" → 60 秒后 `enterParked` → `calibrateSocAtRest` 拿 45 秒窗的
0.9 分位（68.9V）去查表 → 表说 8% → 锚点直接改成 8%，且**下一次推算从这个 8% 继续往下走**。
每个红绿灯/每次 App 重启都会再来一次，于是 26.8km 时就是 3–4%。

## 三、这一版怎么修（四道闸门 + 两个口径修正）

### 1. `停车 = 速度小 且 里程不长`（根因修复）
`tick` 每秒钟记一次"里程是否还在涨"（`tripKm` 增长 > 0.02km → `kmGrowingTs = now`），
`updateStationary` 增加一条：**最近 5 秒里程还在长 → 一律算在动**。
GPS 速度缺失时再也不会把骑行误判成停车；顺带也修掉了"停车态 `trackDist.rebind` + step=0"
把真实里程吃掉的问题。

### 2. `calibrateSocAtRest` 加三道闸门
- 闸门一：最近 90 秒里程还在涨 → 直接跳过，日志写明 `odometer still growing (riding, not parked)`
- 闸门二：45 秒静置窗的 0.9 分位与中位数相差 > 1.2V → 窗口跨了负载变化，跳过
- 闸门三：`restFilter.samplesIn(now) < 10` 跳过。**这里原来是查 5 秒显示窗（voltFilter）**，
  停车后只有 4–5 帧，经常正好卡在门槛下，导致"该校准反而被跳过"——查错了对象，已改。

### 3. 校准改成"三轮"而不是"一进门就校"
铅酸停下后电压要 5–10 分钟才接近开路电压，进停车 60 秒时读到的一定还偏低。
现在：停稳 **120 秒**做第一次粗校，之后每 3 分钟再校一次，一轮停车最多 3 次。
（`restCalCount` / `lastRestCalMs`，`enterParked` 里清零）

### 4. 向下锚定也限额（`SocTracker`）
原来 `anchorRestGuarded` 只在"差 >12 点"时限额，**差 ≤12 点时是整段直接对齐**：
这就是上面"每 30 秒掉 3–11 点"的直接来源。现在：
- 单次停车向下最多 **4 点**；
- 一箱电累计向下最多 **12 点**（`nudgeBudgetPct`，满电锚点时 `resetNudgeBudget()` 归零）；
- **向上**（电压说比推算更好）不限额，立刻对齐——保守方向永远放行。
- 学习样本也用限幅后的值，别把"一次大跳"学成每公里耗电。

### 5. 学习样本加物理区间闸门
`%/km` 样本折算成满电续航必须落在 **20–150km**，否则**直接丢弃**（以前是夹到 3.0%/km，
等于把坏样本当"最高耗电"焊死）。段越长权重越高（2km 段 15%，≥10km 段 50%）。

### 6. 满电锚点去重窗口 6 小时 → 30 分钟
中午回家补一次电，下午出门也该认"满电"；6 小时窗口会让电量停在上午剩的数字。

## 四、顺带的三处体验修

- **字号随格子高度自适应**：`MetricCell` 改 `BoxWithConstraints`，`字号 = 格高 × 0.42`
  夹在 44–80sp。状态栏恢复显示、分屏、系统大字体都不会把大数字裁掉半个。
- **通知栏/岛必须说实话**：未连接时 `statusLine()` 前加「重连中 ·」，不再让锁屏显示上一秒的漂亮数字。
- **通知里加"还能跑"**：`72.3V · 65% · 12.4km · 28km/h · 还能43km`，锁屏一眼够用。
