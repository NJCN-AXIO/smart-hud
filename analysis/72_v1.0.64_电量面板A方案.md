# 72 v1.0.64：电量面板 A 方案落地（电池外框 + 10 格 + 百分比）

## 背景

71 号复盘后先做静态样板 `mockup/battery-panel-sample.html`：A–D 四套面板各跑 82% / 33% / 12% 三档，底部滑块可拖任意电量看颜色与格子数。用户选定 **A：电池外框 + 内部分格 + 右侧大百分比**（最接近成熟电摩仪表）。

## 改动（仅 UI，口径逻辑不变）

- 新增 `SocPanelCell`（`ui/HudScreen.kt`）：
  - 圆角矩形电池外框 + 右侧正极小凸起；
  - 内部 10 段格子，已充段与外框同色（≤20 红 / ≤40 黄 / 其余绿），空段 30% 透明度暗灰；
  - 右侧大字号百分比 + `%` 单位，字号仍随格子高度自适应；
  - 副标题槽位保留，口径文案不变（停稳·按电压 / 骑行·按里程推算 / 断开前读数 / 按里程推算 / 等待电压）。
- 普通三格页与极简两格页的电量格都换成 `SocPanelCell`。
- 移除 v1.0.63 临时的通用底部横条 `BatteryBar` 与 `MetricCell.barPct` 参数，不留两套电量结构。

## 验证

- 红线自检通过（唯一写仍是 CCCD 开通知）。
- `:protocol` 11 条、`:core` 114 条单测全过；`assembleDebug` 通过；APK 101 / 1.0.64 一致，zip CRC 无损坏。
- 待下一车真机确认：窄屏下外框 + 数字是否挤、强光/反光下段数辨识度；必要时把格子 10 → 8 或外框收窄。
