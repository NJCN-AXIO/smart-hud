## 1. "刹车一下整页跳一下"——根因不是刹车，是"有多余的行就改高度"

用户在 09:05 截图里看到的是：

```
连接中                                        -- km/h

        --  .  -- V

            100%

     控制器未连接 · 显示断开前读数

              6.9km
           还能跑 ~80km · 均速 20
          总里程 11306.0 km
 控制器未连接 · 电压为推算值 · 离开 1 小时 17 分未记录里程 ·
 长按总里程可对齐                      ← 折成两行，把上面全顶上去了

  [ 电压 ]  [ 标记 ]  [ 设置 ]
```

根因链（代码层）：

1. 数据区是 `Column(Modifier.weight(1f))`，三个 `MetricCell` 各 `weight(1f)`；
2. 状态行、导航行、定位警告、控制器状态位、总里程行全是**"有内容才渲染"**（`if (...)`）；
3. 这些行一出现就吃掉高度 → 数字区被压缩；
4. 而 `MetricCell` 的字号又是**按格子高度算的**：`vSp = maxHeight × 0.42`。

所以不只是"位置变"，**字号也跟着变**。刹车时控制器报 `刹车` 状态位（多一行）→ 数字变小变高；
松开后那一行消失 → 又变回去。用户看到的就是"像插入了一行、整页跳"。

### 修法：所有信息行改成固定高度槽位

| 区域 | 改动 |
|---|---|
| 顶部行（连接状态 + 时速） | `.heightIn(min = 52.dp)` —— 高度只随系统字体缩放变，不随运行内容变 |
| 总里程行 | 条件渲染 → **固定 26dp 槽位**，没数值时留空 |
| 导航行 | **固定 20dp 槽位**，有导航显示导航，没有留空 |
| 底部信息区 | 两条自然堆叠的短句 → **固定 50dp / 2 行 × 16dp**，各一行、超出省略 |

这样数字区高度 = 屏高 − 52 − 26 − 20 − 50 − 按钮条，是一个**常数**，
三个大数字的基线和字号再也不会因为哪行字冒出来而变。

> 唯一仍会撑高布局的是长按打开的 `diag`。那是"你自己要看"的调试信息，默认不出现，保留完整内容。

- 第一行 = 来源（`已断开 · 上次读数 3 分钟前` / `静置电压` / 空）

这样"长按总里程对齐"这个动作不会再被来源那半句挤掉。

## 3. 导航联动：先让它"能证明自己在工作"

用户说"没有真正和高德地图导航联动"。原来的实现有三个盲区：

1. **没授权时界面什么都不显示** —— 看起来就是"这个 App 没做导航"；
2. **没有任何日志** —— 出问题只能猜"是没收到通知，还是收到了没认出来"；
3. **文案太长** —— 高德原文常是「剩余 3.2 公里 · 12 分钟 · 预计 21:30 到达」，
   13sp 一行放不下，被省略号吃掉一半，看起来像"没联动"。

本轮改动：

- `NavBridge.onListenerConnected()` / `onListenerDisconnected()` 各写一条 `SYS` 日志
  （`nav listener connected`）。**日志里没有这一行，就说明系统没给通知使用权**，不用再猜；
- 每个高德/百度/腾讯通知都写一条（5 秒最多一条）：
  `nav com.autonavi.minimap t=<标题前18字> b=<正文前30字>` —— 能直接看出"收到了但没认出来"还是"压根没收到"；
- 现在也读 `EXTRA_TITLE`（有些版本把"剩余 3.2 公里"放在标题，正文只有"点击查看"）；
- 新增腾讯地图 `com.tencent.map`；
- 文案压缩成一行：`高德 · 剩余 3.2km · 12分`（正则取"X 公里/X 米"和"X 分钟"）；
  取不到才退回原文截断；
- 主界面在**启动后 90 秒内**，如果没授权就显示一行 `导航联动未开 · 设置里打开通知使用权`，
  90 秒后自动消失（避免变成长挂的小字）；
- 能收到通知就顺手把 `HudState.navPerm` 置 true（说明权限确实是开的）。

**开法**：设置 → 通知使用权（导航剩余里程）→ 在系统列表里勾上「智能HUD」。

## 4. 上车验收

1. 主界面**不应该再有上下跳**：连接/断开、刹车、导航来去，三个大数字的位置和字号都不动；
2. 底部信息区最多两行，超出会显示 `…`，不会再折成三行顶布局；
3. 没开通知使用权时，启动后 90 秒内能看到一行提示；开了之后开高德导航，
   20dp 那行应显示 `高德 · 剩余 X km · Y 分`；
4. 如果还是不显示，把日志发出来，搜 `nav ` 和 `nav listener`：
   - 没有 `nav listener connected` → 权限没给；
   - 有 `nav com.autonavi... b=...` 但界面没显示 → 是文案没认出来，把 `b=` 那几行发我，按真实文案再加规则。
