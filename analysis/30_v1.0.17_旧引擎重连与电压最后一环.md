# v1.0.17：旧引擎重连、导航文案抖动、电压"最后一环"

这轮查的是三条平时不显眼、但会直接影响骑车体验的路径。

## 一、旧引擎 `BleLink` 里堆着 v1.0.13 修过、但没修到这里的三颗雷

`NordicBleLink` 是默认引擎，`BleLink` 是设置里关掉 Nordic 之后的兜底。
问题是：**v1.0.13–15 的所有链路修复只打了 Nordic 那份，兜底这份全是旧的**。

| # | 严重度 | 问题 | 后果 |
|---|---|---|---|
| 1 | 🔴 | `h.postDelayed(this::connect, delay)` 每次生成新的 lambda → `removeCallbacks` 删不掉 | 断开一次 + 手动重连一次 = 两条排队任务，各开一条 GATT，互相打断 |
| 2 | 🔴 | `connect()` 顶部没有"已连接/正在连"闸门 | 扫描超时或排队任务一到，就在正在推送的链路上再 `connectGatt` 一次 → 对端踢人 |
| 3 | 🔴 | 扫描的 12 秒超时回调**连上之后照样跑**，末尾无条件 `retryLater(3000)` | 12–15 秒后必断一次，对上"连上十几秒断一次" |
| 4 | 🟠 | `connectGatt` 没有超时看门狗 | 对端不回应时 `connecting` 永远 true → 之后所有重连被闸门挡住，链路彻底死掉 |
| 5 | 🟠 | 断开后无条件 `retryLater(2000)`；133 只提示"连接被拒" | 小程序占着链路时每 2 秒撞一次，把小程序踢掉 |

修法与 Nordic 完全对齐：
- 固定实例 `connectTask` + `scheduleConnect()`（先删再排，绝不叠加）
- `connect()` 顶部加 `if (ready || (connecting && gatt != null)) return;`
- 扫描超时回调里加 `if (ready || connecting) return;`
- 新增 20 秒连接看门狗 `connectWatchdog`（连上即撤，`closeGatt` 也撤）
- 断开时按"这次连了多久"分流：<5s 判被抢，阶梯退避 8→20→45→60s；否则 2s 快回连
- 状态码翻人话：133/8/62 → "控制器被占用：小程序/另一台手机连着它"；19 → "对端主动断开"

## 二、`NavBridge`：那行导航字会来回跳

高德导航时**同时挂着好几条通知**：主文案（"剩余 3.2 公里 · 12 分钟"）、
转向提示（"距前方路口 200 米右转"）、测速提醒、违章提醒。

旧版逻辑是"最后一条匹配就覆盖" → 于是底部那行字在 **"剩余 3.2 公里"** 和 **"200 米右转"** 之间乱跳。

现在分成两级：

- **主文案**：含 `剩余 / 预计 / 到达 / 全程 / 总里程`
- **辅助文案**：其余（转向提示等）
- **保护期 90 秒**：只要 90 秒内出现过主文案，辅助文案不许覆盖它

另外一处：高德刷新常驻通知时常是"先撤再发"，旧版 `onNotificationRemoved` 无条件清空
→ 底部那行字**每刷新一次闪一下空白**。现在"刚更新过 800ms 内"就不清（那只是刷新周期）。

## 三、电压显示的最后一环：停车切静置口径

先说结论：**"小程序 68.6V、App 66.1V"这个差，很可能不是算错，是你们在看两个物理量。**

因为控制器只允许一条连接，你和育宁小程序**永远是不同时刻**在看电压：

- 你打开小程序 = 你已经退掉 HUD、车停着 → 小程序读到的是**静置电压**（不带载、无压降）
- HUD 骑行中读到的是**带载端电压**（爬坡时能低 3–6V）

用你 221542 那份日志验证：49 帧全是 66.0–66.2V，转把 0.8V，故障 0x22（刹车）—— 确实是**停车静置**状态，
说明我们解出来的电压和小程序是同一个字段、同一套公式，没有偏移（`vOffset` 只在旧的 `FieldMap` 路径用，主路径不碰）。
差的那 2V 就是"带载 vs 静置"。

所以这版做了一个对齐动作：

- **停车 ≥12 秒** → 大数字切到**静置电压**（45s/0.9 分位的静置窗口，和小程序同口径）
- **骑行中** → 仍然显示**带载端电压**（这个才有诊断意义：能看出爬坡压降、电池内阻）
- 电压下面那行小字会写清楚当前是哪种：`静置电压 · 骑行时显示带载值`

这样你下次"停车打开小程序对比"时，两个数应该基本一致（±0.3V 内）。

## 五、车上怎么验

1. **停车 15 秒以上**看电压 → 应该和小程序几乎一致；骑行中反而会比小程序低（正常，那是压降）。
2. 骑高德导航 → 底部那行字稳定停在"剩余 X 公里"，不该被"200 米右转"顶掉，也不该每次刷新闪空白。
3. 如果你在设置里关过 Nordic 引擎，这版之后兜底引擎也不会再"连上十几秒断一次"。
