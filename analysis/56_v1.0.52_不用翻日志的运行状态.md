# v1.0.52 · 「不用翻日志」的改动（vc89）

用户原话：**"连上车还要先搜日志 fgs type=? 不搜不行吗 太麻烦 了"**

结论：**不用搜了。** 那条诊断已经搬到界面上，出问题截图就行；主屏也会在最该提示的时候自己说一句话。

## 一、设置页新增「运行状态」卡片

位置：设置 → 设备 → 下面一块（标题「运行状态」）

| 行 | 显示什么 | 怎么看 |
|---|---|---|
| 前台服务 | `连接设备 + 定位 ✅` / `仅连接设备（没定位权限）⚠` | 前者才能在后台继续取点（切高德/锁屏） |
| 定位点 | `正常（3 秒前）✅` / `12 秒前（偏慢）` / `40 秒没点了 ⚠` | ⚠ 就是这个值在停 → 里程不会涨 |
| 后台定位 | `始终允许 ✅` / `仅使用时 ⚠` | 可选项，开了连开机自启都稳 |

**出问题只需要**：打开设置 → 截这一块 → 发我。不用再翻 CSV、不用搜关键字。

---

## 二、主屏只在"真有救"的时候提示一句

```
定位停了 · 设置里改「始终允许」
```

触发条件（三条同时成立，缺一不显示，避免添乱）：

1. 控制器**连着**（`connState = CONNECTED`）；
2. 后台定位**还是**"仅使用时"（`bgLocOk = false`）；
3. 定位点 **25 秒以上没更新**（或本次还没拿到过）。

一旦在设置里改成「始终允许」，这行**永远不会再出现**。
（定位在室内本来就会停，但那时没连车、或者已经不是"仅使用时"，所以不会误报。）

- 日志里那行 `fgs type=..` 保留（我复盘用），但**不再是给你看的操作步骤**。

## 五、上车看一眼就够（30 秒）

1. 打开 App → 连上车 → **直接进设置看「运行状态」**：
   - 第一行是 `连接设备 + 定位 ✅` 就说明后台取点没问题；
   - 第二行 `正常（N 秒前）✅` 说明系统在给点。
2. 想更稳：点上面那行「后台定位：仅使用时」→ 系统里选「始终允许」→ 回来再看，两行都会变 ✅。
3. 之后正常骑，什么都不用管；真出问题就截「运行状态」这块发我。
